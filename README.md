## AI-First Engineering

AI is now a part of my everyday engineering workflow.

I use AI agents for codebase exploration, research, implementation, testing, documentation, code review, and repetitive engineering work. This lets me iterate much faster while keeping architectural decisions, scope, trade-offs, and quality under explicit engineering control.

My approach is **AI-first, not AI-autopilot**:

- define architecture and boundaries before implementation;
- give agents explicit context, constraints, and engineering rules;
- decompose work into small, reviewable changes;
- use tests, static analysis, CI, and independent review as feedback loops;
- optimize for maintainability rather than generated-code volume.
